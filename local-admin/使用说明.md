# Adelaide 防水与贴砖：本地内容后台

桌面双击「Adelaide防水贴砖－内容后台」打开，或运行源码中的「打开本地编辑后台.cmd」。地址为 http://127.0.0.1:8792/admin/ ，仅本机可用；关闭网页不会丢失已保存的草稿，重新开机后双击即可重启后台。

1. 左侧选择页面，或「全站公共文字」。页面标题、正文、SEO 描述、图片说明、结构化资料和现有图片均有相应条目。
2. 搜索文字，点击「编辑」，修改中文并保存草稿；图片条目中用「选择新图片」导入 PNG/JPEG/WebP，最多 10 MB。原图保留，替换后的图片在中英文预览中共用。
3. 点击「中文预览」检查。草稿不是浏览器缓存，保存于 source/.local-admin/state.json；图片保存于 source/assets/uploads。
4. 改错可在「修改记录」恢复。修改了网页并不会改变线上网站，不能直接发布。
5. 改完告诉 Codex：「我改好了，请读取本地后台草稿，同步英文并做本地检查。」没有自动翻译或离线自动监控。

英文待同步时不能生成上传包。Codex 执行 `npm run editor:sync` 导出待核对清单，核对每条英文后执行 `npm run editor:sync -- <同步JSON绝对路径>` 导入；中文修订号必须匹配。

「生成上传包」只在同级 reports/local-admin/releases 生成候选 source 文件夹、source.zip、修改记录和 SHA256 清单。它不会覆盖 source，更不会上传到 Vercel。正式发布前仍须由 Codex 把已核对修改合并回唯一源码、处理草稿基线，再经你当次授权走 GitHub → Vercel；不要自行从候选文件夹直接部署，否则后续可能被覆盖。

注意：带内链的段落会按文字片段显示；保留原链接关系。公司身份、电话、邮箱等事实应通知 Codex 全站核对，不要只改一处文字。FAQ 内容与结构化问答也需同步核对。不要在后台输入客户私密资料或密钥。

后台不提供任意 HTML 编写、页面重排或新增页面。首页轮播现有图片和案例图文保留；编辑后台不自动改变原站设计。后台程序与草稿目录已排除在 Vercel 发布之外。
